## Purpose
This script is for the use in SecureCRT for high level status checsk of a given interface. 

## Intrsuctions

1. In SecureCRT, right-click your Button Bar.

2. Create New Button.

3. Function: Run Script

4. Point it to wherever port-check.py is saved locally.

5. Label it 'Port Check'.

6. While connected to your Cisco switch, click it. You should get the little interface prompt, enter the given port.
